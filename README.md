# LC Pulse

> Track the problems you solve. Measure how you grow.

LC Pulse is a personal LeetCode analytics platform designed to measure
actual problem-solving progress rather than simply tracking activity
streaks.

## The Problem

While practicing DSA, repeatedly solving previously completed problems
is useful for revision, but it can make activity-based metrics such as
streaks less representative of actual new learning.

For example:

- Day 1: 5 problems solved → 4 new, 1 repeated
- Day 2: 5 problems solved → 1 new, 4 repeated

Both days show the same amount of activity, but the amount of new
progress is very different.

LC Pulse aims to solve this by distinguishing first-time solves from
repeated practice.

## Core Idea

A problem is counted as a **new problem** only on the date of its first
Accepted solution.

This allows LC Pulse to calculate:

- Daily new problems
- Monthly progress
- Yearly progress
- All-time growth
- Problem-solving velocity
- Repeated practice activity
